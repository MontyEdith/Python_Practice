FILE HANDLING IN PYTHON ENABLES A PROGRAM TO CREATE, READ, UPDATE, 

AND DELETE FILES STORED PERMANENTLY ON A SECONDARY STORAGE DEVICE. 

THIS PROCESS BRIDGES THE GAP BETWEEN VOLATILE SYSTEM MEMORY (RAM) AND NON-VOLATILE STORAGE, ENSURING THAT DATA PERSISTS

EVEN AFTER THE PROGRAM TERMINATES. PYTHON EXECUTES THESE TASKS USING THE BUILT-IN OPEN(FILENAME, MODE) FUNCTION, WHICH

ACCEPTS THE FILE'S PATH AND A DESIGNATED PROCESSING MODE. THE MOST COMMON MODES INCLUDE 'R' FOR READING EXISTING DATA, 'W' FOR WRITING NEW

TEXT (WHICH ENTIRELY OVERWRITES EXISTING CONTENTS), AND 'A' FOR APPENDING NEW DATA TO THE END OF THE FILE WITHOUT 

DELETING THE ORIGINAL CONTENT
