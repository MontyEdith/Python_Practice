## 📂 Repository Structure

The repository is organized into different folders based on Python topics.

| Folder | Description |
|---|---|
| `Control Flow` | Conditional statements, loops, and decision-making |
| `Data structures` | Lists, Tuples, Sets, Dictionaries, and Strings |
| `Exception Handling` | Error handling, try-except, and custom exceptions |
| `File_handling` | Reading, writing, and managing files |
| `Functions` | Functions, arguments, recursion, and lambda functions |
| `OOPs` | Classes, Objects, Inheritance, Encapsulation, Polymorphism, and Abstraction |
| `Variable_scope` | Local, Global, and Nonlocal variables |

Each folder contains Jupyter Notebooks with practice questions, coding exercises, and implementations of different Python concepts.
